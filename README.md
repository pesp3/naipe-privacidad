# Política de privacidad — Naipe: Card Logic Puzzle

*Contenido de la aplicación → Política de privacidad*:

<https://pesp3.github.io/naipe-privacidad/>

**El original no está aquí.** Vive en el repositorio del juego, en `docs/privacidad/index.html`,
que es privado. Este repositorio es una copia servida: si el texto cambia, se edita allí y se
copia aquí, nunca al revés. `Tools/verify-privacidad.sh` comprueba que las dos coinciden byte a
byte.
